# 🚀 Crypto Slots Telegram Mini App

**Полноценное Telegram Mini App со слот-машиной**

Красивый игровой интерфейс + мощный бэкенд + Telegram-бот + Админка.

![Demo](https://via.placeholder.com/800x400?text=Crypto+Slots+Demo) <!-- Замени на реальный скриншот -->

## ✨ Ключевые возможности

- 🎰 Красивая слот-машина с анимациями
- 🏦 Система баланса и транзакций
- 📊 RTP-симулятор и статистика
- 🏆 Лидерборды и ежедневные бонусы
- 👥 Реферальная система
- 🛠 Админ-панель
- 🐳 Полная поддержка Docker

## 🛠 Стек технологий

- **Frontend**: React 19 + Vite + TypeScript + Tailwind + Framer Motion
- **Backend**: Node.js + Express + TypeScript
- **Bot**: Telegraf
- **DB**: SQLite (better-sqlite3)
- **Validation**: Zod

## 🚀 Быстрый старт

```bash
git clone https://github.com/xelsing1991-maker/crypto-slots-telegram-mini-app.git
cd crypto-slots-telegram-mini-app
npm install
cp .env.example .env
npm run db:migrate
npm run dev
```

## 📊 Математика и RTP

Подробная симуляция RTP доступна через скрипты. Целевой RTP настраивается в `slot_config.json`.
